# 🤖 ربات تولید عدد تصادفی تلگرام

ربات تلگرامی برای تولید عدد تصادفی بین دو عدد مشخص، با امکان ثبت گروه‌ها و تعیین عدد دلخواه برای استفاده در درخواست بعدی.

## ✨ امکانات

- تولید عدد تصادفی با دستور `/rand`
- ثبت گروه با دستور `/register`
- مشاهده گروه‌های ثبت‌شده با `/mygroups`
- منوی دکمه‌ای برای راهنما، معرفی ربات و انتخاب گروه
- وب‌هوک تلگرام و مسیر بررسی سلامت سرویس (`/healthz`)

## 🧰 پیش‌نیازها

- Node.js
- توکن ربات تلگرام از [BotFather](https://t.me/BotFather)
- یک آدرس عمومی HTTPS برای دریافت وب‌هوک

## ⚙️ راه‌اندازی

۱. مخزن را دریافت و وارد پوشه پروژه شوید.

۲. وابستگی‌ها را نصب کنید:

```bash
npm install express node-telegram-bot-api
```

۳. متغیرهای محیطی زیر را تنظیم کنید:

- `BOT_TOKEN`: توکن ربات تلگرام
- `APP_URL`: آدرس عمومی برنامه، بدون `/` در انتها
- `PORT`: پورت سرور (اختیاری؛ مقدار پیش‌فرض `3000`)

نمونه در Linux/macOS:

```bash
export BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"
export APP_URL="https://your-domain.example"
export PORT=3000
node index.js
```

در ویندوز PowerShell:

```powershell
$env:BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"
$env:APP_URL="https://your-domain.example"
$env:PORT="3000"
node index.js
```

> نام `index.js` را در صورت متفاوت بودن نام فایل اصلی، تغییر دهید. آدرس `APP_URL` باید از اینترنت قابل دسترسی و دارای HTTPS معتبر باشد.

## 📋 دستورات

| دستور | کاربرد |
|---|---|
| `/start` | شروع کار و نمایش منو |
| `/rand 1 100` | تولید عدد تصادفی بین دو عدد |
| `/register` | ثبت گروهی که دستور در آن اجرا می‌شود |
| `/mygroups` | نمایش گروه‌های ثبت‌شده در پیام خصوصی |
| `/help` | نمایش راهنما |

## 🔒 نکات مهم

- اطلاعات گروه‌ها و اعداد تنظیم‌شده در حافظه نگهداری می‌شوند؛ با راه‌اندازی مجدد برنامه پاک خواهند شد.
- برای استفاده از وب‌هوک، تلگرام باید بتواند از طریق HTTPS به مسیر `/webhook/<BOT_TOKEN>` دسترسی داشته باشد.
